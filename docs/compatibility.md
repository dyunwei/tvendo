# 支持范围与已知限制

## 已支持

- 自托管网页控制台、API Key、管理员 HTTP / MCP 上游管理。
- 中文 Skill、Go CLI、工具关键词搜索与参数详情；CLI / API 可选跨语言向量召回、Rerank 重排与无匹配时的网页搜索工具推荐。
- 人民币（CNY）固定单次计费，精度为微元；余额预留、成功结算、失败退款、单次与每日预算。
- MCP Streamable HTTP 和旧版 HTTP+SSE 上游；平台对用户提供 REST API。
- CLI 提供 Linux / macOS / Windows 的 amd64 / arm64 程序。Docker 发布目标为 Linux amd64 / arm64。

## 当前边界

支持微信 Native 扫码充值和管理员人工充值。管理员可申请原单全额微信退款并核对微信账单。微信 H5 / JSAPI 和部分退款暂未支持；没有邮件验证 / 找回密码、团队空间、面向用户的 MCP 服务端、异步任务、流式响应、动态路径参数或用量驱动的变动费率。账户密码问题暂由部署方处理。上游接口配置和费率由管理员维护。控制台用量与资金流水支持服务端分页、筛选和 CSV 导出。用户管理最多显示最近 1000 位用户。

- 默认使用关键词检索；语义召回和重排需单独配置模型服务。模型结果受目录说明与阈值影响，可能误召回或漏召回；英文上游说明不会自动翻译，搜索不会自动调用推荐工具。
- HTTP 参数 Schema 由管理员配置，缺失 Schema 时只有参数示例；平台不承诺对所有 Schema 关键字执行完整验证。
- 资源页面和资源 JSON 仅作说明，不提供创建、租赁或生命周期管理。
- MCP 不支持交互式 OAuth、sampling / elicitation、异步长任务、resources / prompts 导入。
- 上游 60 秒超时；平台请求体最多 1 MB，响应最多 8 MB，不流式转发。
- 用量记录提供「查看详情」，展示状态、HTTP 状态码、请求 ID 和耗时；失败时保存错误类型及经过脱敏、限长的错误说明，服务端日志通过调用编号和请求 ID 关联。历史记录的失败原因无法补录。
- 调用记录用于核账。通过幂等键执行的成功调用，其结果加密保存 24 小时，可单独恢复。HTTP 失败仅提取结构化响应的 `message`、`error` 或 `error.message`，其他响应只记录状态码；不保存完整请求或鉴权头。请求标识用于关联查询，幂等键用于去重。
- 每日预算按 UTC 00:00 重置；任务累计额度由 Agent 跟踪，平台没有跨 Agent 的任务预算。

## 验证范围

自动测试使用受控 HTTP / MCP 上游及隔离数据库，不代表每个真实供应商都已验证。平台目录只显示部署管理员实际配置并开放的工具；首页品牌展示不代表已有凭据或集成。跨平台编译通过不等于所有平台均完成运行测试。详见 [验证记录](verification.md)。
