# 支持范围与已知限制

## 已支持

- 自托管网页控制台、API Key、管理员 HTTP / MCP 上游管理。
- 中文 Skill、Go CLI、工具文本搜索与参数详情。
- 固定单次计费、余额预留、成功结算、失败退款、单次与每日预算。
- MCP Streamable HTTP 和旧版 HTTP+SSE 上游；平台对用户提供 REST API。
- CLI 提供 Linux / macOS / Windows 的 amd64 / arm64 程序。Docker 发布目标为 Linux amd64 / arm64。

## 当前边界

人工充值；没有在线支付、邮件验证 / 找回密码、团队空间、面向用户的 MCP 服务端、异步任务、流式响应、动态路径参数或用量驱动的变动费率。账户密码问题暂由部署方处理。上游接口配置和费率由管理员维护。用量与账目各返回最近 200 条，用户管理最多显示最近 1000 位用户。



- 搜索采用名称与描述的文本匹配，不是语义检索；英文上游说明不会自动翻译。
- HTTP 参数 Schema 由管理员配置，缺失 Schema 时只有参数示例；平台不承诺对所有 Schema 关键字执行完整验证。
- 资源页面和资源 JSON 仅作说明，不提供创建、租赁或生命周期管理。
- MCP 不支持交互式 OAuth、sampling / elicitation、异步长任务、resources / prompts 导入。
- 上游 60 秒超时；平台请求体最多 1 MB，响应最多 8 MB，不流式转发。
- 调用记录用于核账，不保存可恢复的完整结果正文。请求标识用于关联查询，不提供幂等保证。
- 每日预算按 UTC 00:00 重置；任务累计额度由 Agent 跟踪，平台没有跨 Agent 的任务预算。

## 验证范围

自动测试使用受控 HTTP / MCP 上游及隔离数据库，不代表每个真实供应商都已验证。平台目录只显示部署管理员实际配置并开放的工具；首页品牌展示不代表已有凭据或集成。跨平台编译通过不等于所有平台均完成运行测试。详见 [验证记录](verification.md)。
